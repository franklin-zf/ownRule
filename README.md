# ownRule

## 中文

Franklin 自用的网络分流规则与配置集合，包含多个服务的列表文件及 Quantumult X 配置。使用前请根据自己的网络环境检查并调整规则。

## English

Franklin's personal collection of network-routing rules and configuration files, including service-specific lists and a Quantumult X configuration. Review and adapt the rules to your own network environment before use.
